Decision (implementation): app.py decomposed into routes/ (pages, sessions, post_session, providers, live) and services/ (runtime, session_runtime, llm, live_pipeline, post_session); app.py is now 101 lines. Refinements made while building, deriving from DECISION-20260928-164322-422043: (1) Added root settings.py for .env loading and config constants, because services cannot import config from app.py without a circular import; app.py imports db before settings so db.DB_PATH keeps its existing env-only precedence. (2) Shared runtime is held in service-module singletons (services.runtime, services.session_runtime.live_session) that routes import, instead of app.state dependency injection; rebound scalars (current session id, summary, seq, generation) became attributes on a SessionState object to avoid stale from-import copies. app.state injection is deferred because it would change every handler signature. (3) Recap and synthesis endpoint bodies stay in routes/post_session.py; only the clean-transcript job machinery moved to services/post_session.py. Extracting the recap/synthesis workflows needs return-path refactoring and is a follow-up. (4) Router include order is pages, post_session, sessions, providers, live, so the literal /v1/sessions/synthesis routes match before /v1/sessions/{session_id}. (5) Private LLM helpers were renamed to public names in services/llm.py; app.py re-exports the old underscored names for replay.py. Verified: 37/37 routes are identical with 0 precedence differences over 102 sample paths; a side-by-side run of the original and refactored servers across 21 REST and WS steps plus the audio and LLM-proxy WS paths was equivalent.
